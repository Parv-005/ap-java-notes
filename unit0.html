Platform Independence PYQ MS25-1a

Java's motto is "Write Once, Run Anywhere" (WORA). A Java program compiled on Windows runs unchanged on Linux or macOS. This works because the compiler does not produce machine code for a particular CPU. It produces bytecode, which is a set of instructions for an imaginary machine called the Java Virtual Machine (JVM).

Hello.java ──javac──▶ Hello.class (bytecode, same file for every OS) │ ┌───────────────────┼───────────────────┐ ▼ ▼ ▼ JVM for Windows JVM for Linux JVM for macOS │ │ │ x86 machine code x86/ARM machine code ARM machine code
  1. Compilation: javac Hello.java checks syntax and types, then writes Hello.class containing bytecode.
  2. Class loading: java Hello starts the JVM. The ClassLoader loads the .class file.
  3. Bytecode verification: the verifier checks the bytecode is safe (see Security).
  4. Execution: the JVM interprets the bytecode. Frequently-run ("hot") code is compiled to native machine code by the JIT (Just-In-Time) compiler for speed.

So the bytecode is platform independent, but the JVM itself is platform dependent: each OS needs its own JVM. Fixed-size primitive types also help: an int is always 32 bits on every platform, unlike C where its size depends on the machine.

        System.out.println("Hello, " + (args.length > 0 ? args[0] : "World"));
    }
}
KeywordWhy it is there

voidmain returns nothing to the JVM. Use System.exit(code) to send an exit status.

Can we change the signature?

  • Allowed: static public void main(String[] args) (modifier order), String args[], String... args (varargs), any parameter name, adding final or synchronized.
  • Not allowed as an entry point: removing public or static, changing the return type, or changing the parameter type. It still compiles, but running fails with "Main method not found".
  • You can overload main (for example main(int x)). The JVM only calls the String[] version.
  • Java 21+ preview (instance main methods) relaxes these rules. For exams, give the classic answer.

Data types, type casting: widening vs narrowing PYQ MS25-3a

Java has 8 primitive types: byte(8 bit), short(16), int(32), long(64), float(32), double(64), char(16, Unicode), boolean. Everything else (arrays, String, your classes) is a reference type.

Type casting converts a value from one type to another.

Widening (automatic, safe): byte → short → int → long → float → double char ↗ Narrowing (explicit cast, may lose data): the reverse direction
int i = 100;
long l = i;          // widening: implicit, no data loss
double d = l;        // widening: 100.0

double pi = 3.99;
int n = (int) pi;    // narrowing: explicit, decimal part dropped → 3
int big = 300;
byte b = (byte) big; // narrowing overflow: 300 - 256 = 44

// Reference casting
Object o = "hello";          // upcasting (implicit)
String s = (String) o;       // downcasting (explicit, checked at runtime)
Integer x = (Integer) o;     // compiles, but throws ClassCastException at runtime
Widening (implicit)Narrowing (explicit)
Smaller type → larger typeLarger type → smaller type
Done automatically by the compilerNeeds a cast operator (type)
No data loss (except some precision for long→float)Possible data loss, truncation or overflow
double d = 10;int i = (int) 10.7;

Autoboxing and unboxing: automatic conversion between primitives and their wrapper classes (int ↔ Integer). Example: List<Integer> l; l.add(5);

Pass by value vs pass by reference PYQ MS25-2b

Pass by value: the method receives a copy of the argument, so changing the parameter doesn't affect the caller. Pass by reference: the method receives an alias to the caller's variable, so reassigning it changes the caller's variable (C++ int&).

Java is ALWAYS pass by value. For objects, the value that gets copied is the reference (the address). The method can therefore modify the object's state through the copied reference, but it cannot make the caller's variable point to a different object.
class Box { int v; Box(int v){ this.v = v; } }

public class PassDemo {
    static void changePrimitive(int x) { x = 99; }
    static void changeState(Box b)     { b.v = 99; }          // modifies the shared object
    static void reassign(Box b)        { b = new Box(-1); }   // only the local copy changes

    public static void main(String[] args) {
        int a = 5;  changePrimitive(a);  System.out.println(a);   // 5
        Box box = new Box(5);
        changeState(box); System.out.println(box.v);             // 99
        reassign(box);    System.out.println(box.v);             // still 99
    }
}

Classic proof: a swap(Box a, Box b) method cannot swap the caller's two variables in Java, but it can in C++ with references.

How Java ensures security PYQ MS25-4a

  1. No explicit pointers: you can't do pointer arithmetic or read arbitrary memory.
  2. Bytecode verifier: before execution, the verifier checks that the bytecode follows Java's rules. It checks for no stack overflow or underflow, correct types for operations, no illegal casts, no jumps into the middle of instructions, access modifiers respected, and final classes/methods not overridden. This protects against hand-crafted or tampered .class files.
  3. Class loader: separates classes into namespaces (bootstrap → platform → application loaders, using parent delegation). A malicious class can't replace core classes such as java.lang.String.
  4. Sandboxing: untrusted code runs in a restricted environment with limited access to the file system, network and system properties. Historically this was the SecurityManager and applets; it is deprecated since Java 17, and modern sandboxing uses containers and the module system.
  5. Automatic memory management: garbage collection removes dangling pointers and double-free bugs. Array bounds are always checked, so buffer overflows aren't possible.
  6. Exception handling, strong typing, and security APIs (JCA: cryptography, java.security, TLS).

Ways to create an object (without new?) PYQ MS25-4b

Yes. Objects can be created without writing new in your code:

// 1. new keyword (normal)
Student s1 = new Student("A");

// 2. Reflection
Student s2 = Student.class.getDeclaredConstructor(String.class).newInstance("B");

// 3. clone()  (class must implement Cloneable) - constructor NOT called
Student s3 = (Student) s1.clone();

// 4. Deserialization - constructor NOT called
ObjectInputStream in = new ObjectInputStream(new FileInputStream("s.ser"));
Student s4 = (Student) in.readObject();

// 5. Factory / static methods (they use new internally)
List<String> list = List.of("x", "y");
Integer i = Integer.valueOf(5);
String str = "literal";   // String literal from the string pool

The this keyword PYQ MS25-5a

this is a reference to the current object, the object on which the method or constructor was called. Uses:

public class Employee {
    private String name;
    private double salary;

    // 1. Resolve name clash between field and parameter (shadowing)
    public Employee(String name, double salary) {
        this.name = name;          // this.name = field, name = parameter
        this.salary = salary;
    }
    // 2. Constructor chaining: call another constructor of the same class (must be the first statement)
    public Employee(String name) { this(name, 30000); }

    // 3. Return current object → method chaining (builder style)
    public Employee raise(double pct) { salary += salary * pct / 100; return this; }

    // 4. Pass current object as argument
    public void register(Registry r) { r.add(this); }

    // 5. Call another method of the current object (implicit, usually omitted)
    public void print() { this.display(); }
    private void display() { System.out.println(name + " " + salary); }
}
// usage: new Employee("Ravi").raise(10).raise(5).print();

this can't be used inside a static method because there is no current object.

Packages PYQ ES25-1a(ii)

A package is a namespace that groups related classes and interfaces, like a folder.

  • Benefits: avoids name clashes (java.util.Date vs java.sql.Date), controls access (package-private), keeps code organised and modular, and makes reuse easier.
  • Built-in: java.lang (auto-imported), java.util, java.io, java.net, java.sql.
  • User-defined: declared with package as the first statement. The directory structure must match.
// file: com/college/util/MathUtil.java
package com.college.util;
public class MathUtil { public static int sq(int x){ return x*x; } }

// file: App.java
import com.college.util.MathUtil;     // or: import com.college.util.*;
import static java.lang.Math.PI;      // static import
public class App { public static void main(String[] a){ System.out.println(MathUtil.sq(4) + PI); } }
javac -d . com/college/util/MathUtil.java App.java
java App

Methods and invoking them from outside a class PYQ MS24-2a

A method is a named block of code that does a task. It has a modifier, return type, name, parameter list and body: access returnType name(params) { body }. Methods define an object's behaviour.

  • Instance method: called on an object: obj.method().
  • Static method: called on the class: ClassName.method().
  • To call it from outside the class, it must be visible (public, or default within the same package).
class Calculator {
    public int add(int a, int b) { return a + b; }           // instance method
    public static int square(int x) { return x * x; }        // static method
    private void secret() {}                                 // not callable from outside
}
public class Main {
    public static void main(String[] args) {
        Calculator c = new Calculator();
        System.out.println(c.add(2, 3));             // 5   via object reference
        System.out.println(Calculator.square(4));    // 16  via class name
        // c.secret();  // compile error: secret() has private access
    }
}

Destructors? Garbage collection PYQ MS24-3a

Java has no destructors. Memory is reclaimed automatically by the Garbage Collector (GC) when an object is no longer reachable from any live reference.

  • An object becomes eligible for GC when: the reference is set to null, it is reassigned to another object, or the object was created inside a method that has returned.
  • System.gc() only requests a GC. It isn't guaranteed to run.
  • finalize() was the closest thing to a destructor. It is unreliable and deprecated since Java 9.
  • For releasing resources such as files or sockets, use try-with-resources and AutoCloseable.

Operators and control structures Lab 1 Lab 2

Lab 1: Calculator (+, −, ×, ÷)
import java.util.Scanner;

public class Calculator {
    static double calculate(double a, double b, char op) {
        switch (op) {
            case '+': return a + b;
            case '-': return a - b;
            case '*': return a * b;
            case '/':
                if (b == 0) throw new ArithmeticException("Division by zero");
                return a / b;
            default: throw new IllegalArgumentException("Unknown operator: " + op);
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        while (true) {
            System.out.print("Enter expression (e.g. 4 * 5) or 'q' to quit: ");
            String first = sc.next();
            if (first.equalsIgnoreCase("q")) break;
            try {
                double a = Double.parseDouble(first);
                char op  = sc.next().charAt(0);
                double b = sc.nextDouble();
                System.out.println("Result = " + calculate(a, b, op));
            } catch (ArithmeticException | IllegalArgumentException e) {
                System.out.println("Error: " + e.getMessage());
            }
        }
        sc.close();
    }
}
Output
Enter expression (e.g. 4 * 5) or 'q' to quit: 12 / 4
Result = 3.0
Enter expression (e.g. 4 * 5) or 'q' to quit: 5 / 0
Error: Division by zero

Integer division: 7/2 = 3 (int), 7/2.0 = 3.5. % gives the remainder. Integer division by 0 throws ArithmeticException, while double division by 0 gives Infinity.

Lab 2: if / else / switch / for / while / do-while
public class ControlStructures {
    public static void main(String[] args) {
        int marks = 78;

        // if - else if - else
        if (marks >= 90)      System.out.println("Grade A+");
        else if (marks >= 75) System.out.println("Grade A");
        else if (marks >= 50) System.out.println("Grade B");
        else                  System.out.println("Fail");

        // switch (classic, with fall-through prevented by break)
        int day = 3;
        switch (day) {
            case 1: System.out.println("Mon"); break;
            case 2: System.out.println("Tue"); break;
            case 3: System.out.println("Wed"); break;
            default: System.out.println("Other");
        }
        // switch expression (Java 14+)
        String type = switch (day) { case 6, 7 -> "Weekend"; default -> "Weekday"; };
        System.out.println(type);

        // for: multiplication table
        for (int i = 1; i <= 5; i++) System.out.print(7 * i + " ");
        System.out.println();

        // enhanced for
        int[] arr = {3, 1, 4};
        for (int x : arr) System.out.print(x + " ");
        System.out.println();

        // while: sum of digits (condition checked first, may run 0 times)
        int n = 1234, sum = 0;
        while (n > 0) { sum += n % 10; n /= 10; }
        System.out.println("Digit sum = " + sum);

        // do-while: body runs at least once
        int k = 10;
        do { System.out.println("do-while ran with k=" + k); k++; } while (k < 5);

        // break & continue
        for (int i = 1; i <= 10; i++) {
            if (i % 2 == 0) continue;   // skip evens
            if (i > 7) break;           // stop loop
            System.out.print(i + " ");  // 1 3 5 7
        }
    }
}
