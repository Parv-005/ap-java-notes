How to use these notes

  • Each topic heading has red PYQ tags showing which exam asked it, and blue Lab tags for practicals.
  • Code blocks are complete programs you can copy into a .java file and run (JavaFX needs the OpenJFX SDK, JDBC needs a driver JAR, JUnit needs the junit-jupiter dependency).
  • The sidebar on each page is an auto-generated table of contents. The ◐ Theme button switches light/dark mode. Ctrl+P prints cleanly (the sidebar is hidden).
  • Code examples target Java 17+ (records, switch expressions, instanceof patterns). Older-style alternatives are shown where exams expect them.
