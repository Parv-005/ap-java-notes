Object Cloning PYQ ES25-3bPYQ MJ26-5a

Cloning creates an exact copy of an existing object. Java gives you Object.clone(), a protected native method that allocates a new object of the same class and copies every field without calling a constructor.

Steps to make a class cloneable

  1. Implement the marker interface Cloneable. Otherwise Object.clone() throws CloneNotSupportedException.
  2. Override clone() as public (optionally with a covariant return type).
  3. Call super.clone(), then deep-copy any mutable fields.

Shallow copy vs deep copy

Shallow copy (the default super.clone()): primitives are copied, but references are copied as references. So the original and the clone share nested objects, and changing a nested object through one is visible through the other.
Deep copy: nested mutable objects are also cloned recursively, so the copy is fully independent.

SHALLOW DEEP orig ──▶ [name, addr ●]──┐ orig ──▶ [name, addr ●]──▶ [Address: Delhi] ├─▶ [Address] copy ──▶ [name, addr ●]──▶ [Address: Delhi] (separate) copy ──▶ [name, addr ●]──┘
class Address implements Cloneable {
    String city;
    Address(String c) { city = c; }
    @Override protected Address clone() throws CloneNotSupportedException { return (Address) super.clone(); }
}

class Employee implements Cloneable {
    String name;              // immutable - safe to share
    int[] scores;             // mutable array
    Address addr;             // mutable object

    Employee(String n, int[] s, Address a) { name = n; scores = s; addr = a; }

    Employee shallowCopy() throws CloneNotSupportedException {
        return (Employee) super.clone();               // field-by-field copy
    }
    @Override public Employee clone() throws CloneNotSupportedException {   // DEEP
        Employee e = (Employee) super.clone();
        e.scores = scores.clone();                     // arrays have a public clone()
        e.addr   = addr.clone();                       // clone nested object
        return e;
    }
    // Alternative that many prefer: a copy constructor
    Employee(Employee o) { this(o.name, o.scores.clone(), new Address(o.addr.city)); }
}

public class CloneDemo {
    public static void main(String[] args) throws Exception {
        Employee orig = new Employee("Asha", new int[]{90, 80}, new Address("Delhi"));

        Employee sh = orig.shallowCopy();
        sh.addr.city = "Mumbai"; sh.scores[0] = 0;
        System.out.println("After shallow change, orig: " + orig.addr.city + " " + orig.scores[0]);

        orig.addr.city = "Delhi"; orig.scores[0] = 90;     // reset
        Employee dp = orig.clone();
        dp.addr.city = "Pune"; dp.scores[0] = 0;
        System.out.println("After deep change, orig:    " + orig.addr.city + " " + orig.scores[0]);
        System.out.println(orig != dp && orig.getClass() == dp.getClass());
    }
}

Advantages of cloning: fast copying of complex objects without repeating construction logic. Copies keep the exact runtime class. Useful for the Prototype pattern and for defensive copies.
Limitations: Cloneable has no clone() method, which is a design flaw. The checked CloneNotSupportedException clutters code. It is shallow by default, so deep copy is manual and error-prone. Constructors aren't called, so invariants and counters are skipped. It doesn't work well with final fields, which can't be reassigned after super.clone(). Every class in the hierarchy must cooperate. Effective Java recommends copy constructors or static factory methods instead.

Generic Programming PYQ EJ26-3a

Generics let classes, interfaces and methods take type parameters, so one piece of code works with many types and stays type-safe at compile time.

// Without generics (pre-Java 5)
List list = new ArrayList();
list.add("hi"); list.add(42);           // anything goes
String s = (String) list.get(1);        // compiles, but ClassCastException at RUNTIME

// With generics
List<String> names = new ArrayList<>();  // diamond operator <>
names.add("hi");
// names.add(42);                        // COMPILE error - bug caught early
String t = names.get(0);                // no cast needed

Benefits: ① compile-time type checking ② no explicit casts ③ reusable algorithms (one sort for all types) ④ self-documenting APIs.

Generic classes, methods, bounded types, wildcards

// Generic class with type parameter T
class Box<T> {
    private T value;
    void set(T v) { value = v; }
    T get() { return value; }
}

// Two type parameters
class Pair<K, V> {
    final K key; final V val;
    Pair(K k, V v) { key = k; val = v; }
}

// Generic method: <T> before the return type
class Util {
    static <T> void printAll(T[] arr) { for (T x : arr) System.out.print(x + " "); System.out.println(); }

    // Bounded type: T must be Comparable to itself
    static <T extends Comparable<T>> T max(List<T> list) {
        T best = list.get(0);
        for (T x : list) if (x.compareTo(best) > 0) best = x;
        return best;
    }

    // Upper-bounded wildcard: read from a list of any Number subtype (PRODUCER)
    static double sum(List<? extends Number> nums) {
        double s = 0; for (Number n : nums) s += n.doubleValue(); return s;
    }
    // Lower-bounded wildcard: write Integers into a list of Integer or its supertypes (CONSUMER)
    static void fill(List<? super Integer> dst) { for (int i = 0; i < 3; i++) dst.add(i); }

    // Unbounded wildcard
    static int size(List<?> anything) { return anything.size(); }
}

public class GenericsDemo {
    public static void main(String[] args) {
        Box<Integer> b = new Box<>(); b.set(10); int x = b.get();
        Pair<String, Integer> p = new Pair<>("age", 20);
        Util.printAll(new String[]{"a", "b"});
        System.out.println(Util.max(List.of(3, 9, 2)));          // 9
        System.out.println(Util.sum(List.of(1, 2.5, 3L)));       // 6.5
        List<Number> nums = new ArrayList<>(); Util.fill(nums);  // [0, 1, 2]
    }
}
  • PECS rule: Producer Extends, Consumer Super.
  • Type erasure: generic type information is removed after compilation (List<String> becomes List in bytecode). As a result you can't do new T(), new T[], instanceof List<String>, or use primitives as type arguments (List<int> isn't allowed, use Integer).
  • List<Integer> is not a subtype of List<Number> (generics are invariant). Use wildcards.
  • Naming conventions: T = Type, E = Element, K = Key, V = Value, N = Number.

Defensive and Secure Programming PYQ ES25-3c

Defensive programming means writing code that keeps working correctly, or fails safely and clearly, even when it gets unexpected inputs, misuse, or bad conditions. The mindset is: "never trust input, never assume". Secure programming applies the same idea against malicious inputs, to prevent vulnerabilities.

Techniques

  1. Validate all inputs (parameters, user input, files, network). Check null, range, format and length, and fail fast with clear exceptions: Objects.requireNonNull, IllegalArgumentException.
  2. Preconditions and postconditions. Use assertions for internal invariants and exceptions for public API checks.
  3. Encapsulation: private fields, the least visibility needed, final where possible.
  4. Immutability and defensive copying of mutable inputs and outputs (see immutable classes).
  5. Proper exception handling: don't swallow exceptions, don't leak stack traces or internal details to users, and clean up with try-with-resources.
  6. Avoid injection: use PreparedStatement for SQL and never build queries by string concatenation. Escape output (XSS).
  7. Least privilege: grant only the permissions that are needed. Don't hard-code secrets.
  8. Handle sensitive data carefully: store passwords in char[] and clear them after use, hash passwords (bcrypt), use SecureRandom not Random, and use transient for secret fields that must not be serialized.
  9. Guard against deserialization attacks: never deserialize untrusted data, or use ObjectInputFilter.
  10. Fail securely: on error, deny access rather than allow it.
  11. Thread safety for shared state.
  12. Testing (unit tests, edge cases), code review, and static analysis.
public final class BankAccount {
    private final String owner;
    private long balancePaise;                                   // avoid double for money

    public BankAccount(String owner, long openingPaise) {
        this.owner = Objects.requireNonNull(owner, "owner");     // fail fast on null
        if (owner.isBlank()) throw new IllegalArgumentException("owner blank");
        if (openingPaise < 0) throw new IllegalArgumentException("negative opening balance");
        this.balancePaise = openingPaise;
    }
    public synchronized void withdraw(long amt) {
        if (amt <= 0) throw new IllegalArgumentException("amount must be > 0");
        if (amt > balancePaise) throw new IllegalStateException("insufficient funds");
        balancePaise -= amt;
        assert balancePaise >= 0 : "invariant broken";           // internal sanity check
    }
    // SQL: secure version
    static ResultSet find(Connection c, String user) throws SQLException {
        PreparedStatement ps = c.prepareStatement("SELECT * FROM users WHERE name = ?");
        ps.setString(1, user);              // input can't change the query → no SQL injection
        return ps.executeQuery();
    }
}

Importance in secure software design: most security bugs (injection, buffer and integer overflows, null dereferences, broken access control) come from unchecked assumptions. Defensive code shrinks the attack surface, makes failures visible and contained instead of silently corrupting data, and makes the system more reliable and easier to maintain.

Exception Handling PYQ ES24-2bPYQ ES25-3aPYQ EJ26-2bPYQ MJ26-5bLab 10

An exception is an event that disrupts the normal flow of a program at runtime (dividing by zero, a missing file, a bad index). When it happens, the JVM creates an exception object and throws it. The runtime searches back up the call stack for a matching handler (catch). If none is found, the thread ends and the stack trace is printed.

Exception hierarchy

The five keywords: try, catch, finally, throw, throws PYQ ES25-3a

tryEncloses code that might throw. Must be followed by catch and/or finally.
catchHandles a specific exception type. Order matters: put specific types before general ones. Multi-catch: catch (A | B e).
finallyAlways runs, whether or not an exception occurred, even after return. Used for cleanup. It doesn't run only if the JVM exits (System.exit) or crashes.
throwThrows an exception object explicitly: throw new IllegalArgumentException("x"). Used inside a method body, one object at a time.
throwsIn a method signature: declares exceptions the method may pass to its caller: void read() throws IOException, SQLException.
Lab 10: try-catch-finally + ArrayIndexOutOfBounds (ES24-2b) + multiple catch + user-defined exception (EJ26-2b)
import java.util.Scanner;

// User-defined CHECKED exception (extend RuntimeException for unchecked)
class InsufficientBalanceException extends Exception {
    private final double shortBy;
    public InsufficientBalanceException(String msg, double shortBy) {
        super(msg);
        this.shortBy = shortBy;
    }
    public double getShortBy() { return shortBy; }
}

class Account {
    private double balance = 1000;
    // 'throws' declares; 'throw' raises
    void withdraw(double amt) throws InsufficientBalanceException {
        if (amt > balance)
            throw new InsufficientBalanceException("Balance too low", amt - balance);
        balance -= amt;
        System.out.println("Withdrawn " + amt + ", left " + balance);
    }
}

public class ExceptionDemo {
    public static void main(String[] args) {
        int[] arr = {10, 20, 30};

        // 1. ArrayIndexOutOfBoundsException
        try {
            System.out.println("Accessing index 5...");
            System.out.println(arr[5]);                       // throws
            System.out.println("never printed");
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Caught: " + e.getMessage());
        } finally {
            System.out.println("finally #1 always runs");
        }

        // 2. Multiple catch blocks - most specific first
        String[] inputs = {"5", "0", "abc", null};
        for (String in : inputs) {
            try {
                int d = Integer.parseInt(in.trim());           // NPE for null, NFE for "abc"
                System.out.println("100/" + d + " = " + (100 / d));  // ArithmeticException for 0
            } catch (ArithmeticException e) {
                System.out.println("Math error: " + e.getMessage());
            } catch (NumberFormatException e) {
                System.out.println("Not a number: " + in);
            } catch (Exception e) {                            // general handler LAST
                System.out.println("Other: " + e.getClass().getSimpleName());
            } finally {
                System.out.println("  (finished input " + in + ")");
            }
        }

        // 3. User-defined exception
        Account acc = new Account();
        try {
            acc.withdraw(300);
            acc.withdraw(900);
        } catch (InsufficientBalanceException e) {
            System.out.println(e.getMessage() + ", short by " + e.getShortBy());
        }

        // 4. try-with-resources: resource closed automatically (Java 7+)
        try (Scanner sc = new Scanner("42")) {
            System.out.println("Read: " + sc.nextInt());
        }
    }
}

Program flow: when a statement throws, the rest of the try block is skipped. The JVM checks the catch blocks top to bottom and runs the first one whose type matches (by IS-A). Then finally runs, and execution continues after the whole try statement. If no catch matches, finally still runs and the exception goes up to the caller. Putting catch(Exception) before catch(ArithmeticException) is a compile error (unreachable code).

final vs finally vs finalize: final is a keyword (constant, no override, no subclass). finally is the block that always runs. finalize() is the deprecated GC hook.

Assertions PYQ ES24-3aPYQ MJ26-5b

An assertion is a statement of something the programmer believes is always true at that point. If it is false, the JVM throws an AssertionError. Assertions are for catching bugs during development and testing, not for handling expected errors.

assert condition;                    // form 1
assert condition : "message expr";   // form 2 - message shown in the AssertionError

Disabled by default. Turn them on with java -ea MyApp (enable assertions) and off with -da. When disabled, they cost nothing.

public class AssertDemo {
    static int percentage(int obtained, int total) {
        assert total > 0 : "total must be positive, got " + total;     // precondition (private use)
        int pct = obtained * 100 / total;
        assert pct >= 0 && pct <= 100 : "pct out of range: " + pct;  // postcondition
        return pct;
    }
    public static void main(String[] args) {
        System.out.println(percentage(45, 50));
        System.out.println(percentage(60, 50));     // bug in data → assertion fails with -ea
    }
}
$ java AssertDemo          → 90  then 120  (assertions off: bug goes unnoticed)
$ java -ea AssertDemo      → 90  then
Exception in thread "main" java.lang.AssertionError: pct out of range: 120

Rules: don't use assertions to validate public method arguments or user input, because they can be disabled. Use exceptions for that. Never put side effects inside an assert (assert list.remove(x); is wrong). Use them for internal invariants, "impossible" default branches in a switch, and pre/postconditions of private methods.

File processing with exceptions + assertions (MJ26-5b)

import java.io.*;
import java.nio.file.*;
import java.util.*;

public class UserFileReader {
    record User(String name, int age) {}

    static List<User> load(Path file) throws IOException {
        List<User> users = new ArrayList<>();
        try (BufferedReader br = Files.newBufferedReader(file)) {        // auto-close
            String line; int lineNo = 0;
            while ((line = br.readLine()) != null) {
                lineNo++;
                if (line.isBlank()) continue;
                String[] parts = line.split(",");
                try {
                    if (parts.length != 2) throw new IllegalArgumentException("expected 2 fields");
                    int age = Integer.parseInt(parts[1].trim());
                    if (age < 0 || age > 150) throw new IllegalArgumentException("bad age " + age);
                    users.add(new User(parts[0].trim(), age));
                } catch (IllegalArgumentException e) {                   // includes NumberFormatException
                    System.err.println("Skipping line " + lineNo + ": " + e.getMessage());
                }
            }
        }
        assert users.stream().allMatch(u -> u.age() >= 0) : "validation bug";   // internal check
        return users;
    }

    public static void main(String[] args) {
        try {
            System.out.println(load(Path.of("users.csv")));
        } catch (NoSuchFileException e) {
            System.out.println("File not found: " + e.getFile());
        } catch (IOException e) {
            System.out.println("I/O failure: " + e.getMessage());
        }
    }
}

Explanation: exceptions handle conditions you expect and can recover from: a missing file, a malformed line (it is skipped and logged, and the program goes on). Try-with-resources guarantees the file is closed. The assertion checks the program's own logic. If it ever fires, the validation code has a bug.

Collection Framework PYQ ES24-3cPYQ EJ26-3a

The Java Collections Framework (JCF), in java.util, is a unified architecture for storing and working with groups of objects. It has three parts:

  1. Interfaces: abstract data types (Collection, List, Set, Queue, Deque, Map).
  2. Implementations: concrete classes (ArrayList, LinkedList, HashSet, TreeSet, HashMap, PriorityQueue...).
  3. Algorithms: static methods in Collections (sort, binarySearch, reverse, shuffle, max, min, frequency, unmodifiableList, synchronizedList).

Why it is important: no need to write your own data structures. The implementations are fast and well tested. Code works through interfaces, so implementations can be swapped. The collections resize themselves (unlike arrays). Generics give type safety. Different APIs can pass collections to each other. Iteration, streams and sorting are already there.

ArrayList, HashSet, HashMap demo (ES24-3c)

import java.util.*;

public class CollectionsDemo {
    public static void main(String[] args) {
        // ArrayList: ordered, indexed, duplicates allowed
        List<String> fruits = new ArrayList<>();
        fruits.add("Mango"); fruits.add("Apple"); fruits.add("Banana"); fruits.add("Apple");
        fruits.add(1, "Kiwi");                 // insert at index
        fruits.remove("Banana");
        System.out.println("ArrayList: " + fruits + " size=" + fruits.size() + " get(0)=" + fruits.get(0));
        Collections.sort(fruits);
        System.out.println("Sorted:    " + fruits);

        // HashSet: no duplicates, no guaranteed order
        Set<String> unique = new HashSet<>(fruits);
        unique.add("Apple");                   // ignored, already present → add() returns false
        System.out.println("HashSet:   " + unique + " contains Kiwi? " + unique.contains("Kiwi"));

        // HashMap: key → value, keys unique
        Map<String, Integer> stock = new HashMap<>();
        stock.put("Apple", 50); stock.put("Mango", 20); stock.put("Apple", 75);   // overwrites
        stock.putIfAbsent("Kiwi", 10);
        stock.merge("Mango", 5, Integer::sum);                                    // 25
        System.out.println("HashMap:   " + stock + " Apple=" + stock.get("Apple"));
        for (Map.Entry<String, Integer> e : stock.entrySet())
            System.out.println("  " + e.getKey() + " → " + e.getValue());

        // Iterator: safe removal while iterating
        Iterator<String> it = fruits.iterator();
        while (it.hasNext()) if (it.next().startsWith("A")) it.remove();
        System.out.println("After removing A*: " + fruits);
    }
}

How HashMap works internally

A HashMap holds an array of buckets. For put(k, v): ① compute k.hashCode(), mix its bits, and take index = hash & (n-1) ② if the bucket is empty, store the entry ③ otherwise walk the bucket and use equals() to find the same key and replace its value, or else append the entry (a collision). Since Java 8, a bucket with more than 8 entries turns into a red-black tree. When size exceeds capacity × loadFactor (0.75), the table doubles and entries are rehashed. This is why equals/hashCode must be consistent.

Employee storage with searching and sorting (EJ26-3a)

import java.util.*;
import java.util.stream.*;

record Employee(int id, String name, String dept, double salary) {}

public class EmployeeDirectory {
    private final Map<Integer, Employee> byId = new HashMap<>();   // O(1) lookup by id
    private final List<Employee> all = new ArrayList<>();          // for ordering

    void add(Employee e) {
        if (byId.putIfAbsent(e.id(), e) != null) throw new IllegalArgumentException("Duplicate id " + e.id());
        all.add(e);
    }
    Optional<Employee> findById(int id) { return Optional.ofNullable(byId.get(id)); }
    List<Employee> findByDept(String d) { return all.stream().filter(e -> e.dept().equalsIgnoreCase(d)).toList(); }

    List<Employee> sortedBy(Comparator<Employee> c) { List<Employee> copy = new ArrayList<>(all); copy.sort(c); return copy; }

    int binarySearchByName(String name) {                         // list must be sorted by the same key
        List<Employee> sorted = sortedBy(Comparator.comparing(Employee::name));
        return Collections.binarySearch(sorted, new Employee(0, name, "", 0), Comparator.comparing(Employee::name));
    }

    public static void main(String[] args) {
        EmployeeDirectory d = new EmployeeDirectory();
        d.add(new Employee(103, "Ravi", "IT", 65000));
        d.add(new Employee(101, "Asha", "HR", 55000));
        d.add(new Employee(102, "Kiran", "IT", 72000));
        d.add(new Employee(104, "Meena", "Finance", 61000));

        System.out.println("Find 102: " + d.findById(102).map(Employee::name).orElse("none"));
        System.out.println("IT dept: " + d.findByDept("it"));
        System.out.println("By salary desc:");
        d.sortedBy(Comparator.comparingDouble(Employee::salary).reversed()).forEach(System.out::println);
        System.out.println("Index of Meena in name-sorted list: " + d.binarySearchByName("Meena"));
        Map<String, Double> avg = d.all.stream().collect(Collectors.groupingBy(Employee::dept, TreeMap::new,
                Collectors.averagingDouble(Employee::salary)));
        System.out.println("Avg salary per dept: " + avg);
    }
}

Why these collections: a HashMap gives O(1) search by id. An ArrayList keeps the records in a sortable sequence. A TreeMap keeps the department report in alphabetical order.

Lab 8: Simple Linked List implementation Lab 8

public class MyLinkedList<T> {
    private class Node {                       // inner node class
        T data; Node next;
        Node(T d) { data = d; }
    }
    private Node head;
    private int size;

    public void addFirst(T val) { Node n = new Node(val); n.next = head; head = n; size++; }

    public void addLast(T val) {
        Node n = new Node(val);
        if (head == null) { head = n; }
        else { Node cur = head; while (cur.next != null) cur = cur.next; cur.next = n; }
        size++;
    }
    public void insertAt(int index, T val) {
        if (index < 0 || index > size) throw new IndexOutOfBoundsException("Index: " + index);
        if (index == 0) { addFirst(val); return; }
        Node prev = head;
        for (int i = 0; i < index - 1; i++) prev = prev.next;
        Node n = new Node(val); n.next = prev.next; prev.next = n; size++;
    }
    public boolean delete(T val) {                    // delete first occurrence
        if (head == null) return false;
        if (head.data.equals(val)) { head = head.next; size--; return true; }
        Node cur = head;
        while (cur.next != null && !cur.next.data.equals(val)) cur = cur.next;
        if (cur.next == null) return false;
        cur.next = cur.next.next;                     // unlink
        size--; return true;
    }
    public boolean contains(T val) { for (Node c = head; c != null; c = c.next) if (c.data.equals(val)) return true; return false; }

    public void reverse() {
        Node prev = null, cur = head;
        while (cur != null) { Node nxt = cur.next; cur.next = prev; prev = cur; cur = nxt; }
        head = prev;
    }
    public void traverse() {
        StringBuilder sb = new StringBuilder("[");
        for (Node c = head; c != null; c = c.next) sb.append(c.data).append(c.next != null ? " → " : "");
        System.out.println(sb.append("] size=").append(size));
    }
    public static void main(String[] args) {
        MyLinkedList<Integer> list = new MyLinkedList<>();
        list.addLast(10); list.addLast(20); list.addLast(30);
        list.addFirst(5); list.insertAt(2, 15);
        list.traverse();

Lab 9: Stack (array-based and linked-list-based) Lab 9

A stack is LIFO (Last In, First Out). Operations: push (add to the top), pop (remove the top), peek (look at the top), isEmpty. All are O(1).

// Array implementation
class ArrayStack {
    private final int[] data;
    private int top = -1;
    ArrayStack(int capacity) { data = new int[capacity]; }

    void push(int x) {
        if (top == data.length - 1) throw new IllegalStateException("Stack Overflow");
        data[++top] = x;
    }
    int pop() {
        if (isEmpty()) throw new IllegalStateException("Stack Underflow");
        return data[top--];
    }
    int peek() {
        if (isEmpty()) throw new IllegalStateException("Stack is empty");
        return data[top];
    }
    boolean isEmpty() { return top == -1; }
    int size() { return top + 1; }
}

// Linked-list implementation (generic, unbounded)
class LinkedStack<T> {
    private static class Node<T> { T val; Node<T> next; Node(T v, Node<T> n){ val = v; next = n; } }
    private Node<T> top; private int size;
    void push(T x) { top = new Node<>(x, top); size++; }
    T pop()  { if (top == null) throw new java.util.EmptyStackException(); T v = top.val; top = top.next; size--; return v; }
    T peek() { if (top == null) throw new java.util.EmptyStackException(); return top.val; }
    boolean isEmpty() { return top == null; }
}

public class StackDemo {
    // Application: balanced brackets
    static boolean balanced(String s) {
        LinkedStack<Character> st = new LinkedStack<>();
        for (char c : s.toCharArray()) {
            if ("([{".indexOf(c) >= 0) st.push(c);
            else if (")]}".indexOf(c) >= 0) {
                if (st.isEmpty()) return false;
                char o = st.pop();
                if ("([{".indexOf(o) != ")]}".indexOf(c)) return false;
            }
        }
        return st.isEmpty();
    }
    public static void main(String[] args) {
        ArrayStack s = new ArrayStack(3);
        s.push(10); s.push(20); s.push(30);
        System.out.println("peek = " + s.peek());     // 30
        System.out.println("pop  = " + s.pop());      // 30
        System.out.println("pop  = " + s.pop());      // 20
        System.out.println("size = " + s.size());     // 1
        try { s.push(1); s.push(2); s.push(3); } catch (IllegalStateException e) { System.out.println(e.getMessage()); }
        System.out.println(balanced("{[()()]}") + " " + balanced("([)]"));   // true false
        // Built-in: prefer ArrayDeque over legacy java.util.Stack
        java.util.Deque<Integer> dq = new java.util.ArrayDeque<>(); dq.push(1); dq.push(2); System.out.println(dq.pop()); // 2
    }
}

I/O Streams PYQ ES25-1a(iii,iv)Lab 16

A stream is a sequence of data flowing from a source to a destination. An input stream reads data into the program. An output stream writes data out of it. The source or destination can be a file, the console, a network socket, a memory array and so on. Package: java.io (plus java.nio.file for the modern API).

Byte streams vs character streams

Byte streamCharacter stream
Unit8-bit bytes (raw binary)16-bit Unicode characters
Abstract base classesInputStream, OutputStreamReader, Writer
Main classesFileInputStream, FileOutputStream, BufferedInputStream, DataInputStream, ObjectInputStreamFileReader, FileWriter, BufferedReader, BufferedWriter, PrintWriter, InputStreamReader
Use forImages, audio, video, .class files, serialized objectsText files (.txt, .csv, .java)
EncodingNoneHandles charset encoding/decoding (UTF-8...)

"Entity byte" / byte stream (ES25-1a iv): a byte stream treats data as raw bytes and doesn't interpret them. Character stream (iii): a stream that reads and writes characters and converts bytes to chars with a charset. InputStreamReader and OutputStreamWriter are bridges from byte streams to character streams.

Buffered streams wrap another stream and read or write in large chunks, cutting the number of system calls. This is the Decorator pattern: new BufferedReader(new FileReader("a.txt")).

Standard streams: System.in (InputStream), System.out, System.err (PrintStream).

import java.io.*;

public class FileIODemo {
    public static void main(String[] args) {
        String file = "students.txt";

        // 1. WRITE text with a character stream (BufferedWriter over FileWriter)
        try (BufferedWriter bw = new BufferedWriter(new FileWriter(file))) {   // overwrite mode
            bw.write("101,Asha,91"); bw.newLine();
            bw.write("102,Ravi,78"); bw.newLine();

        // 2. APPEND with PrintWriter
        try (PrintWriter pw = new PrintWriter(new FileWriter(file, true))) {    // true = append
            pw.printf("%d,%s,%d%n", 103, "Kiran", 85);
        } catch (IOException e) { e.printStackTrace(); }

        try (BufferedReader br = new BufferedReader(new FileReader(file))) {
            String line; int total = 0, n = 0;
            while ((line = br.readLine()) != null) {
                String[] p = line.split(",");
                System.out.println("Roll " + p[0] + " → " + p[1] + " scored " + p[2]);
                total += Integer.parseInt(p[2]); n++;
            }
            System.out.println("Average = " + (double) total / n);
        } catch (FileNotFoundException e) {
            System.out.println("File missing");
        } catch (IOException e) { e.printStackTrace(); }

        // 4. BYTE stream copy (works for any file type, e.g. images)
        try (InputStream in = new BufferedInputStream(new FileInputStream(file));
             OutputStream out = new BufferedOutputStream(new FileOutputStream("copy.txt"))) {
            byte[] buf = new byte[4096]; int read;
            while ((read = in.read(buf)) != -1) out.write(buf, 0, read);

            System.out.println("Exists? " + Files.exists(Path.of("copy.txt")) + ", size " + Files.size(Path.of("copy.txt")));
        } catch (IOException e) { e.printStackTrace(); }

Object Serialization and Deserialization PYQ ES24-3aPYQ EJ26-3b

Serialization converts an object's state into a byte stream so it can be saved to a file or database, or sent over a network. Deserialization is the reverse: rebuilding the object in memory from those bytes.

Functions and classes used (ES24-3a)

  • The class must implement the marker interface java.io.Serializable.
  • ObjectOutputStream.writeObject(Object) serializes.
  • ObjectInputStream.readObject() deserializes. It returns Object, so you cast it, and it throws ClassNotFoundException and IOException.
  • serialVersionUID: a version number. If the sender's and receiver's class versions don't match, you get InvalidClassException.
  • transient fields are not serialized. They come back with default values (null/0). Use this for passwords, caches and derived data. static fields aren't serialized either, because they belong to the class.
  • Optional hooks: private void writeObject(ObjectOutputStream) / readObject(ObjectInputStream) for custom logic, and the Externalizable interface for full control.
import java.io.*;

class Address implements Serializable {             // nested objects must ALSO be Serializable
    private static final long serialVersionUID = 1L;
    String city; Address(String c) { city = c; }
}

class Employee implements Serializable {
    private static final long serialVersionUID = 1L;
    private int id;
    private String name;
    private double salary;
    private Address address;                        // serialized too (object graph)
    private transient String password;              // NOT serialized
    static String company = "Acme";                 // NOT serialized (class-level)

    Employee(int id, String name, double salary, Address a, String pwd) {
        this.id = id; this.name = name; this.salary = salary; this.address = a; this.password = pwd;
    }
    @Override public String toString() {
        return id + ", " + name + ", " + salary + ", " + address.city + ", pwd=" + password;
    }
}

public class SerializationDemo {
    public static void main(String[] args) {
        Employee e = new Employee(1, "Asha", 75000, new Address("Delhi"), "secret123");

        // SERIALIZE
        try (ObjectOutputStream out = new ObjectOutputStream(new FileOutputStream("emp.ser"))) {
            out.writeObject(e);
            System.out.println("Serialized:   " + e);
        } catch (IOException ex) { ex.printStackTrace(); }

        // DESERIALIZE
        try (ObjectInputStream in = new ObjectInputStream(new FileInputStream("emp.ser"))) {
            Employee copy = (Employee) in.readObject();     // constructor is NOT called
            System.out.println("Deserialized: " + copy);
            System.out.println("Same object? " + (copy == e));
        } catch (IOException | ClassNotFoundException ex) { ex.printStackTrace(); }
    }
}
Output
Serialized:   1, Asha, 75000.0, Delhi, pwd=secret123
Deserialized: 1, Asha, 75000.0, Delhi, pwd=null
Same object? false

Practical applications: saving application or game state to disk; sending objects across a network (Java RMI, sockets); caching (session replication in web servers); deep copying (serialize, then deserialize); message queues. Modern systems often prefer JSON or Protobuf because they work across languages and are safer.
Security warning: deserializing untrusted data can run attacker-controlled code (gadget chains). See defensive programming.

JDBC: Database Connectivity Lab 13

Not in the theory syllabus, but it is a lab experiment.

JDBC (Java Database Connectivity) is the standard API (java.sql) for connecting Java programs to relational databases. A database-specific driver (MySQL Connector/J, PostgreSQL, SQLite JDBC) implements the API.

Steps

  1. Add the driver JAR to the classpath. (Loading it with Class.forName("com.mysql.cj.jdbc.Driver") is optional since JDBC 4.)
  2. Open a connection: DriverManager.getConnection(url, user, pass).
  3. Create a Statement / PreparedStatement.
  4. Run it: executeQuery() (SELECT, returns a ResultSet) or executeUpdate() (INSERT/UPDATE/DELETE, returns the row count).
  5. Read the ResultSet with next(), getInt and getString.
  6. Close the resources (try-with-resources).
import java.sql.*;

public class JdbcDemo {
    // MySQL: "jdbc:mysql://localhost:3306/college"   SQLite: "jdbc:sqlite:college.db"
    static final String URL = "jdbc:mysql://localhost:3306/college";
    static final String USER = "root", PASS = "password";

    public static void main(String[] args) {
        try (Connection con = DriverManager.getConnection(URL, USER, PASS)) {
            System.out.println("Connected to " + con.getMetaData().getDatabaseProductName());

            try (Statement st = con.createStatement()) {
                st.executeUpdate("CREATE TABLE IF NOT EXISTS student (" +
                        "roll INT PRIMARY KEY, name VARCHAR(50), cgpa DOUBLE)");
                st.executeUpdate("DELETE FROM student");
            }

            // INSERT with PreparedStatement (safe from SQL injection)
            String ins = "INSERT INTO student (roll, name, cgpa) VALUES (?, ?, ?)";
            try (PreparedStatement ps = con.prepareStatement(ins)) {
                Object[][] rows = { {1, "Asha", 9.1}, {2, "Ravi", 7.8}, {3, "Kiran", 8.5} };
                for (Object[] r : rows) {
                    ps.setInt(1, (int) r[0]); ps.setString(2, (String) r[1]); ps.setDouble(3, (double) r[2]);
                    ps.addBatch();
                }
                ps.executeBatch();
            }

            // UPDATE
            try (PreparedStatement ps = con.prepareStatement("UPDATE student SET cgpa = ? WHERE roll = ?")) {
                ps.setDouble(1, 8.0); ps.setInt(2, 2);
                System.out.println("Rows updated: " + ps.executeUpdate());
            }

            // SELECT and retrieve results
            try (PreparedStatement ps = con.prepareStatement("SELECT roll, name, cgpa FROM student WHERE cgpa > ? ORDER BY cgpa DESC")) {
                ps.setDouble(1, 7.5);
                try (ResultSet rs = ps.executeQuery()) {
                    System.out.println("Roll | Name  | CGPA");
                    while (rs.next())
                        System.out.printf("%4d | %-5s | %.1f%n", rs.getInt("roll"), rs.getString("name"), rs.getDouble("cgpa"));
                }
            }

            // Transaction
            con.setAutoCommit(false);
            try (Statement st = con.createStatement()) {
                st.executeUpdate("UPDATE student SET cgpa = cgpa + 0.1 WHERE roll = 1");
                con.commit();
            } catch (SQLException e) { con.rollback(); throw e; }
        } catch (SQLException e) {
            System.out.println("DB error: " + e.getMessage() + " (SQLState " + e.getSQLState() + ")");
        }
    }
}
Compile & run (MySQL):   javac JdbcDemo.java
                         java -cp .:mysql-connector-j-8.x.jar JdbcDemo      (use ; instead of : on Windows)

Statement vs PreparedStatement: PreparedStatement is precompiled (faster when run repeatedly), takes parameters with ?, and is safe from SQL injection. Always prefer it.

Unit Testing using JUnit PYQ ES24-4b

Unit testing tests the smallest testable parts of a program (methods, classes) in isolation, automatically, to check they behave as expected. JUnit is the standard Java framework for it. The current version is JUnit 5 (Jupiter).

Benefits: bugs are found early; refactoring is safe (regression tests); tests document intended behaviour; better design (testable code tends to be modular); fits into CI/CD pipelines; supports TDD (red → green → refactor).

  • JUnit Platform: the foundation for launching testing frameworks. It defines the TestEngine API that tools and IDEs use to discover and run tests.

abstract class Person { protected int id; protected String name; }
class Doctor extends Person {

    boolean isFree(LocalDateTime t) { return !booked.contains(t); }
}
class Patient extends Person {
    private final MedicalRecord record = new MedicalRecord();      // composition
    List<Appointment> appointments = new ArrayList<>();            // association
    Appointment book(Doctor d, LocalDateTime t) {
        if (!d.isFree(t)) throw new IllegalStateException("Slot taken");
        Appointment a = new Appointment(this, d, t);
        d.booked.add(t); appointments.add(a); return a;
    }
}

}
